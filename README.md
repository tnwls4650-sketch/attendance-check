# 출석체크

교육 참석자가 이름을 입력하면 **조와 좌석**을 바로 알려주는 간단한 출석·좌석 안내 페이지입니다. 설치나 서버가 필요 없고, 명단 파일만 바꾸면 다른 교육에서도 그대로 쓸 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 (수정할 필요 없음) |
| `data/roster.js` | **명단 파일 — 교육마다 이 파일만 수정** |

## 다른 교육에 쓰는 방법

`data/roster.js`를 열어 아래 항목만 바꾸면 됩니다.

- `title` : 페이지 제목 (기본 "출석체크")
- `subtitle` : 교육명·부서명 등 부제목
- `teams` : 조 개수
- `qrUrl` : 참가자용 QR이 가리킬 주소 (관리자 화면에 표시)
- `people` : 참석자 명단. 한 줄에 `["성명", "직급", "팀", "파트"]`

조 편성은 **팀 기준으로 자동**됩니다. 같은 팀 사람이 한 조에 몰리지 않도록 인원이 많은 팀부터 조에 돌아가며 배정합니다. 불참자는 `people`에서 빼면 됩니다.

## 화면 설명

- **참가자 화면:** 이름을 입력하면 조·좌석과 전체 조 위치를 보여줍니다.
- **관리자 화면:** 주소 뒤에 `?admin=1`을 붙이거나, 제목을 5번 연속 누르면 열립니다. 참가자용 QR과 조별 명단을 볼 수 있습니다.

## 배포 (GitHub Pages)

1. 이 폴더를 공개 저장소로 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `/ (root)`로 지정합니다.
3. 발급된 주소(`https://<계정>.github.io/<저장소>/`)를 QR 또는 단축 주소(tinyurl)의 대상으로 연결합니다.

> 공개 저장소이므로 명단(이름·팀)이 공개됩니다. 민감한 정보가 포함되지 않는지 확인하고 사용하세요.

## 로컬에서 미리보기

`index.html`을 브라우저로 열면 됩니다. QR 표시에는 인터넷 연결이 필요합니다.
